# 하나의 행성 — 식량 위기

여섯 나라가 연결된 세계에서 식량, 예산, 시설과 외교를 운영하는 한국어 턴제 게임입니다. 다른 나라들도 자국 상황과 이전 결정에 따라 전략을 바꿉니다. 정해진 10턴 종료 없이 계속 운영할 수 있습니다.

**[바로 플레이](https://dael0207.github.io/one-planet-food-crisis/)** · **[자세한 플레이 가이드](PLAYING.md)**

설치나 로그인이 필요 없습니다. 휴대폰의 Safari·Chrome 또는 PC 브라우저에서 플레이 링크를 여세요. 홈 화면에 즐겨찾기를 추가할 수 있습니다. 인터넷 연결이 필요하며 오프라인 앱은 아닙니다.

## 처음 5분

1. 상단 **나라 바꾸기**에서 운영 국가를 고르세요. 처음에는 식량이 넉넉한 **세라**가 쉽습니다. 지도에서 다른 나라를 누르는 것은 정보 확인이며 운영 국가 변경과 다릅니다.
2. **이번 분기 우선 과제**와 식량·국고·물가를 확인하세요. **첫 명령 고르기**를 누르면 선택지로 이동합니다.
3. 명령의 **효과와 대가**를 비교하고 하나를 선택한 뒤 **실행**을 누르세요. 선택·정보 확인·협상 조건 편집만으로는 시간이 흐르지 않습니다.
4. 한 분기가 진행되면 **결과 보기**에서 직접 효과, 다른 요인, 투자 완공 예정과 타국 반응을 확인하세요.
5. 다음 분기 현안을 열어 다시 운영하세요. 투자·협정·외국 대응은 여러 분기 지속될 수 있습니다.

## 할 수 있는 일

- **국내 운영:** 정책, 긴급 식량 대책, 예산 관리, 상황과 이전 결정에 따른 추가 명령.
- **지도 시설:** 도시·국제 항만·지역 농경지를 선택해 관리·투자. 지도 도구로 확대·이동.
- **농경지 풍경:** 공사 구역이 완공되면 경작지가 넓어집니다. 완료한 분기의 가뭄과 이후 회복 흔적이 땅에 남으며, 농지를 누르면 기후·수확 기여와 공사 기간을 확인합니다.
- **외교:** 식량 매매·지원, 상대 조건에 대한 역제안, 장기 무역 협정·동맹.
- **국제 분쟁:** 제재 참여·중립, 제재 완화·평화 중재, 합의 이행과 위반 대응.
- **해외 공동 투자:** 외국 항만·농경지에 투자하고 실제 공급·수익 배분과 중단 위험 관리.
- **장기 계획:** 국가별 목표 달성, 타국의 적응형 전략·협력·견제 확인.
- **운영 기록:** 여러 분기의 지표·관계 그래프, 투자 성과와 결정 타임라인.

## 저장 안내

진행 단계는 해당 브라우저의 로컬 저장소에 자동 저장됩니다. 국가별 기록은 서로 분리됩니다. PC·휴대폰 간 동기화와 저장 파일 내보내기 기능은 현재 없습니다. 기존 ChatGPT Site와 GitHub Pages도 주소가 달라 저장 기록을 공유하지 않습니다. 브라우저 데이터 삭제·시크릿 모드 종료 시 기록을 잃을 수 있습니다.

공개 저장소나 서버로 플레이 기록을 업로드하지 않습니다. 싱글 플레이 게임이며 다른 나라는 시뮬레이션이 운영합니다.

## 로컬 실행

Node.js 24 이상을 사용합니다. 별도 패키지 설치는 필요 없습니다.

```sh
git clone https://github.com/dael0207/one-planet-food-crisis.git
cd one-planet-food-crisis
npm start
```

`http://127.0.0.1:8787/`을 여세요. 로컬 개발 서버는 PC의 루프백 주소에만 바인딩됩니다. 휴대폰에서는 공개 플레이 링크를 사용하세요.

```sh
npm test
```

## 배포와 소스

`main`에 푸시하면 GitHub Actions가 전체 테스트를 실행하고 통과한 `dist/`만 GitHub Pages에 배포합니다. Actions에서 배포 상태를 확인할 수 있습니다. 게임은 빌드가 필요 없는 HTML/CSS/ES 모듈이며 외부 API 키 없이 실행됩니다.

- `dist/`: 게임과 지도 자산
- `tests/`: 시뮬레이션·저장·화면 회귀 테스트
- `PLAYING.md`: 상세 운영 가이드
- `.github/workflows/pages.yml`: 테스트·배포 워크플로

공개 버전은 V29 게임을 기반으로 농경지 투자·가뭄·회복을 지도에서 확인하는 V30 업데이트를 포함합니다. 호스팅 계정 설정·인증 정보·개인 저장 기록·내부 검수 파일은 포함하지 않습니다. 지도 지형과 시설의 일부 시각 자산은 생성형 이미지 도구로 제작했습니다. 세계와 수치는 게임용 가상 모델입니다.
